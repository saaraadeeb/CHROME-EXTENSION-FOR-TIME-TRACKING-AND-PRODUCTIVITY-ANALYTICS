##As part of my Full Stack Development internship, I developed a Chrome Extension for Time Tracking using web development technologies. The main objective of this project is to track the time spent on different websites in the Google Chrome browser. This project helped me understand how browser extensions work and how frontend technologies are used in real-world applications.

The project was developed using HTML, CSS, and JavaScript in Visual Studio Code (VS Code). HTML was used to create the structure of the popup interface, CSS was used for designing and styling the extension, and JavaScript was used to add functionality and website tracking features. The extension was tested and executed in the Google Chrome browser.

The Chrome extension works by detecting active browser tabs and monitoring website changes. Whenever the user switches from one tab to another, the extension records the website name and calculates the amount of time spent on that website. The tracking process runs in the background using a background script file. The extension uses browser permissions through the manifest.json file to access tabs and track website activity properly.

The project contains multiple files including manifest.json, background.js, popup.html, popup.js, and style.css. The manifest.json file is the main configuration file of the extension that defines permissions, popup settings, and background scripts. The background.js file is responsible for tracking websites and calculating time spent on tabs. The popup.html file creates the popup window interface shown when the extension icon is clicked. The popup.js file controls popup functionality, and the style.css file is used for designing the popup window.

During the implementation of this project, I learned how to load extensions into Google Chrome using Developer Mode and the Load Unpacked feature. I also learned how browser APIs work and how JavaScript can be used to interact with browser tabs and user activity. The project improved my knowledge of frontend development concepts and browser extension architecture.

This project also helped me improve problem-solving and debugging skills. While developing the extension, I learned how to identify errors, reload extensions, inspect background scripts, and test functionality in Chrome DevTools. I gained practical experience in handling files, writing JavaScript logic, and organizing project folders properly.

The popup interface of the extension provides a simple and user-friendly design. The extension successfully displays tracking messages and runs website tracking functionality in the background. The project demonstrates the practical implementation of JavaScript and browser extension development concepts.

Overall, this task gave me hands-on experience in Full Stack Development and improved my understanding of Chrome extension development. It enhanced my technical skills in HTML, CSS, JavaScript, debugging, browser APIs, and project management. This internship task helped me gain confidence in developing real-time web applications and browser-based tools using modern web technologies.
